# Hiba's Portfolio

A personal portfolio website showcasing my projects, skills, and frontend development experience, built with React and deployed on Vercel.

[Live Demo](https://hiba-portfolio-gray.vercel.app)

## Sections

* Hero
* Projects
* Skills
* Contact

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS

## Getting Started

### Installation

```bash
npm install
npm run dev
```
